<h2>📌 About This Repository</h2>
<p>
The <strong>Coding_Udinus-</strong> repository contains a collection of C++ programming exercises, 
assignments, and practice files created during coursework at Universitas Dian Nuswantoro (Udinus).
This project is designed to strengthen understanding of basic-to-intermediate C++ concepts—including 
variables, loops, functions, pointers, object-oriented programming, and problem solving.
</p>

<h2>🚀 What You Will Find</h2>
<ul>
  <li>Beginner-friendly C++ program examples</li>
  <li>Console applications with clean, readable structure</li>
  <li>Exercises covering logic, loops, arrays, structs, and more</li>
  <li>Well-organized folders for different topics</li>
</ul>

<br/>

<h2>🛠 Installation & Setup</h2>

<h3>📥 1. Clone the Repository</h3>
<pre>
git clone https://github.com/PVegananda/Coding_Udinus-
cd Coding_Udinus-
</pre>

<br/>

<h2>💽 Running C++ Programs</h2>

<h3>🍎 On macOS (MacBook)</h3>
<ol>
  <li>Check if the Clang compiler is installed:</li>
</ol>
<pre>clang++ --version</pre>

<ol start="2">
  <li>Compile a C++ file:</li>
</ol>
<pre>clang++ filename.cpp -o output</pre>

<ol start="3">
  <li>Run the program:</li>
</ol>
<pre>./output</pre>

<br/>

<h3>🪟 On Windows</h3>
<p>You can use <strong>MinGW</strong>, <strong>MSVC</strong>, or <strong>CodeBlocks</strong>.</p>

<ol>
  <li>Install MinGW (recommended Windows compiler)</li>
  <li>Open Command Prompt</li>
</ol>

<pre>
g++ filename.cpp -o output.exe
output.exe
</pre>

<br/>

<h2>🧪 Example Compilation (Linux/macOS)</h2>
<pre>
g++ main.cpp -o main
./main
</pre>
